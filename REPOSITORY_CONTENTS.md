# Repository contents

This publication includes project source code, tests, historical source, the dashboard template, research reports, and research configuration files. It is an unfinished research snapshot.

Raw participant datasets, derived recording exports, downloaded third-party repositories/data, local Python environments, editor settings, logs, and large generated experiment artifacts are excluded. Some scripts and report links depend on those local artifacts and will not work from this repository alone. Trained model binaries are excluded from this public snapshot. Dataset access and redistribution remain subject to their providers' terms. Third-party attribution is retained in THIRD_PARTY_NOTICES_PUBLISHED.md.
